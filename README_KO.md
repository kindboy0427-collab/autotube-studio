# AutoTube Studio v1.4 — 유튜브를 보고 배우는 AI + 과학·교육 다채널 롱폼 자동 제작

AI가 유튜브 롱폼을 **스스로 찾아 시청·분석**해 "무엇이 시청 유지와 참여를 만드는지" 학습하고,
주제나 명령만 주면 그 학습 결과를 반영해 **대본 → 내레이션 → 영상·이미지 → 배경음악 → 자막 → 썸네일 → 비공개 업로드**까지 자동으로 만듭니다.
공개는 Kim님이 검토한 뒤 버튼으로 합니다.

## 0. 실행·업데이트 (v1.4부터)
- **실행**: 바탕화면(또는 시작 메뉴)의 **AutoTube Studio** 아이콘. 브라우저 탭이 아니라 별도 앱 창으로 열립니다.
- **창을 닫아도** AI 학습·제작은 뒤에서 계속됩니다. 완전히 끄려면 창 오른쪽 위 **[프로그램 종료]**.
- **자동 업데이트**: 켤 때, 그리고 3시간마다 새 버전을 확인해 스스로 내려받아 적용하고 다시 시작합니다(제작 중이면 끝난 뒤).
  data(키·목소리·학습 기록)·output(영상)·.venv는 건드리지 않고, 새 버전이 실패하면 이전 버전으로 자동 복구합니다.
  설정 탭에서 끄거나 [지금 업데이트 확인]을 누를 수 있습니다. 업데이트 저장소가 비공개면 설정 → API 키에 GITHUB_TOKEN(읽기 전용)을 넣으세요.
- 기록: data/logs/engine.log, launcher.log

## 1. 처음 설치 (10분)

1. **Python 3.11 이상** 설치 (python.org, 설치 화면에서 "Add to PATH" 체크)
2. 이 폴더에서 `START_WINDOWS.cmd` 더블클릭 (처음 한 번만) → 환경 구성 후 바탕화면에 **AutoTube Studio** 아이콘이 생기고 앱 창이 열립니다.
3. **설정 탭 → API 키** 입력

| 키 | 용도 | 필수 |
|---|---|---|
| GEMINI_API_KEY | AI 영상 시청·분석, 대본, AI 이미지, AI 영상 클립 | 필수 |
| YOUTUBE_API_KEY | 영상 검색·조회수·댓글 (Google Cloud에서 YouTube Data API v3 사용 설정) | 필수 |
| OPENAI_API_KEY | 요금제 한도 초과 시 대본, 보조 음성 | 선택 |
| ELEVENLABS_API_KEY | 내 목소리 복제(선택), 감정 연기, 배경음악 | 선택 (내레이션은 Gemini가 기본) |
| PEXELS_API_KEY | 무료 스톡 영상·사진 (pexels.com/api, 무료) | 권장 |
| APIFY_TOKEN | Gemini 무료 시청 한도를 넘으면 자막으로 저렴하게 계속 분석 (약 $0.003/편) | 선택 |

4. **구독 요금제 연결 (추천)**: `SETUP_SUBSCRIPTIONS.cmd` 실행. Claude Code와 Codex(각 회사의 공식 명령창 도구)를 설치하고 **Claude Pro·ChatGPT Plus 계정으로 로그인**합니다. Node.js가 필요합니다. 이후 대본·검수·학습 정리는 **추가 비용 없이** 요금제 사용량으로 처리됩니다.
5. **채널 탭**에서 과학·교육 프리셋(우주·천문 / 인체·생물 / 물리·화학 원리 / 기술·미래과학 / 과학사·발명)을 추가하거나 직접 만듭니다. AI 학습은 채널 분야별로 따로 쌓입니다.
6. **YouTube 계정 연결** (채널마다 한 번)
   - Google Cloud 콘솔 → API 및 서비스 → OAuth 동의 화면 설정 → 사용자 인증 정보 → **OAuth 클라이언트 ID (데스크톱 앱)** 생성
   - 내려받은 JSON을 `data\client_secret.json`으로 저장 (모든 채널 공용)
   - 채널 탭 → 각 채널의 [YouTube 연결] (또는 `CONNECT_YOUTUBE.cmd 채널ID`) → 브라우저에서 **그 채널의** Google 계정으로 허용
7. (선택) `AUTOSTART_ON_LOGIN.cmd` — PC를 켜면 화면 없이 조용히 실행되어 학습이 계속됩니다.

## 2. 사용법

- **영상 만들기 탭**: 주제/명령과 길이를 넣고 [AI에게 제작 맡기기]. 10분 영상 기준 수십 분 걸립니다.
- **제작 목록 탭**: 진행률, 완성 영상 미리보기, 썸네일, 제목 후보, 설명, 고정 댓글, 장면별 대본, 작업 기록.
  - 실패하면 [이어서 다시 시도] → 이미 만든 음성·영상은 재사용하고 멈춘 곳부터 이어갑니다.
  - 검토 후 [검토 완료 → 공개].
- **AI 학습 탭**: 학습된 플레이북(성과를 올린 특징 / 피해야 할 특징), 주간 정리, 최근 분석 영상. 참고하고 싶은 영상 주소를 직접 추가할 수도 있습니다.

## 3. 이미 결제 중인 요금제 활용 (v1.2)

| 작업 | 쓰는 AI (자동 순서) | 추가 비용 |
|---|---|---|
| 대본·장면 기획·자체 검수·규칙 정리·주제 추천 | Claude Pro(Claude Code) → ChatGPT Plus(Codex) → OpenAI API → Gemini API | 요금제 한도 안에서는 0원 |
| 영상 화면·소리 시청 분석 | Gemini API (유튜브 링크 시청) | Gemini 요금 |
| 자막으로 분석(대체 시청) | Apify 자막 ($0.003/편) + Claude Pro/ChatGPT Plus | 거의 0원 |
| AI 이미지·영상, 내레이션, 음악 | Gemini, ElevenLabs(구독 크레딧 공유) 등 API | 사용량만큼 |

- 요금제는 **공식 도구(Claude Code의 `claude -p`, Codex의 `codex exec`)**로만 사용합니다. 화면 자동 조작으로 ChatGPT 앱을 쓰는 방식은 OpenAI 약관(자동 추출 금지) 위반이라 넣지 않았습니다.
- 한 요금제가 사용량 한도에 걸리면 1시간 동안 쉬고 다음 AI로 넘어갑니다. 대시보드에 "한도로 잠시 쉬는 중"으로 표시됩니다.
- Plus의 Codex 한도는 "일주일에 몇 번의 집중 작업" 수준이라, 하루 여러 편을 만들면 API로 넘어가는 비중이 늘어납니다. 사용량·주기 탭에서 실제 비율을 확인하세요.

## 3-1. v1.3 새 기능 — 내 목소리 · 대본 틀 · 설명란

**내 목소리 (목소리 탭)**
1. 조용한 방에서, 같은 마이크(휴대폰 녹음 앱 OK)·같은 자리에서 두 파일을 녹음합니다.
   - ① 목소리 샘플: 화면의 예시 문장을 평소 말투로 20~30초 (ElevenLabs도 쓸 거면 3~5분 길게 하나 더)
   - ② 동의 녹음(Gemini용): 화면의 동의 문장을 **토씨 하나 틀리지 않고** 그대로
2. 목소리 탭에서 두 파일을 고르고 Gemini / ElevenLabs 중 등록할 곳을 체크 → 등록.
   프로그램이 24kHz 모노 WAV로 바꾸고 샘플은 28초로 잘라 보냅니다. 파일은 이 PC와 선택한 서비스 사이에서만 오갑니다.
3. **목소리 오디션**: 같은 문장을 내 목소리(Gemini)·내 목소리(ElevenLabs)·Gemini 기본 목소리 등으로 만들어 나란히 듣고 고릅니다.
4. 채널 탭 → 설정에서 채널별 내레이션 목소리를 고릅니다. "강조 장면만 다른 목소리"에 ElevenLabs를 넣으면 훅·반전 장면만 감정 연기가 강한 목소리로 읽습니다(두 목소리가 모두 내 목소리일 때 추천).
- Gemini 복제 목소리는 Google에 1년 보관되고, 만든 음성에는 보이지 않는 SynthID 워터마크가 들어갑니다. 실제 목소리는 **결제를 연결한 유료 등급 키**로 등록하세요(무료 등급 데이터는 제품 개선에 쓰일 수 있음).
- Gemini TTS 요금은 2026년 기준 오디오 1분 약 $0.0135이고, 2027-01-01부터 2배가 됩니다 → 그때 설정의 `prices.gemini_tts_per_minute`를 0.027로 바꾸세요.

**대본 틀 (영상 만들기 탭)** — 좋아하신 레퍼런스 영상 4편의 *구조만* 뽑아 만든 틀입니다(대사·화면은 베끼지 않음).
| 틀 | 어울리는 주제 |
|---|---|
| 반전 논제형 에세이 | "왜 ~할까?" 통념이 있는 주제 — 질문 → 뒤집기 → 커지는 사례 3개 → 반례 → 2차 결론 → 희망 → 열린 질문 |
| 정리형 | 헷갈리는 종류·개념 정리 — 시의성 → 익숙한 것부터 낯선 것으로 → 항목마다 의외의 사실 하나 |
| 단계형 시나리오 다큐 | 위험·미래·과정 — 콜드오픈 → 세 줄 요약 → 1~4단계(실험·숫자) → 찬반 → 희망 → 몇 단계? 질문 |
| 비유 관통형 다큐 | 큰 질문의 긴 영상 — 강한 비유로 시작 → 질문 3개 → 역사 비유 → 반대 의견 → 첫 비유로 수미상관 |
| 원리 해설형 | 현상의 원리 설명 |
"자동"이면 주제에 맞게 AI가 고릅니다. 핵심 문장 뒤에는 1.2초 쉼을 두어 음악이 살짝 올라오게 합니다(설정 `emphasis_pause_seconds`).

**취향 레퍼런스** — 위 4편은 처음 실행할 때 학습 대기열 맨 앞에 자동으로 들어가고, 일반 영상보다 3배 무게로 학습됩니다. AI 학습 탭에서 "내 취향 레퍼런스"를 체크하고 주소를 넣으면 더 추가할 수 있습니다.

**설명란 자동 완성** — 요약·챕터 목차·📚참고 자료(AI가 확실하다고 한 것만, 공개 전 직접 확인)·AI 음성/재연 고지·Pexels 작가·음악 출처.
assets/music 폴더의 음악은 파일 이름이 그대로 출처로 적히니 `Pixabay - 작곡가 - 곡명.mp3`처럼 이름을 지어 두세요.

## 4. 채널·사용량·소재 레이더

- **영상 1편 사용량**: 제작 목록에서 영상을 열면 항목별 사용량·비용·단계별 소요 시간이 나옵니다. 항목은 대본·검수 토큰, AI 영상 초, AI 이미지 장, 내레이션 글자, 음악 분, YouTube 할당량입니다.
- **사용량·주기 탭**: 완성 영상의 평균 비용·제작 시간과 최근 30일 학습 비용으로 **월 예산 안에서 만들 수 있는 편수**와 **채널별 권장 업로드 간격**을 계산합니다. 채널마다 같은 금액을 배정하므로, 제작비가 싼 채널은 더 자주 올릴 수 있습니다.
- **소재 레이더**: 채널 탭에서 [최신 영상 검색]을 누른 뒤(할당량 사용) [지금 뜰 주제 추천]을 누릅니다.
  - 최근 2주 안에 올라온 영상 중 **구독자는 적은데 조회수가 높은 영상**을 찾습니다. 보고 싶은 사람은 많은데 만드는 채널이 적은 주제라는 신호입니다.
  - 이를 바탕으로 채널에 맞는 주제 5개와, 시청자가 들어올 때 → 나갈 때의 감정을 제안합니다.
- **제작 규칙(스킬)**: 영상을 보고 피드백("배경음악이 크다", "수식은 화면 글자로")을 적으면 AI가 채널 규칙을 짧게 갱신하고, 다음 영상부터 반영합니다.
- **자체 검수**: 대본 초안이 나오면 "편집장 겸 과학 감수자" 역할의 AI가 한 번 더 검토합니다. 첫 5초에 감정을 건드리는지, 지루한 장면이 없는지, 과학적 오류·과장이 없는지를 봅니다. 공개 전 확인할 사실·수치는 **사실 확인 목록**으로 따로 보여줍니다.

## 5. AI가 배우는 방식

1. **찾기**: 채널 분야 키워드(+설정의 학습 분야, 최근 제작 주제)로 롱폼(4분 이상)을 검색 → 조회수·구독자 수·참여율 수집 → **채널 크기 대비 조회수가 높은 영상(알고리즘이 밀어준 영상)**에 높은 우선순위.
2. **시청**: Gemini가 공개 영상 URL을 **화면과 소리 모두** 보고 분석 (다운로드 없음). 무료 한도(하루 8시간)를 넘으면 Apify 키가 있을 때 **자막으로 계속 분석**합니다(화면 항목은 비워 둠). 도입 15초, 구간 구조, 이탈 방지 장치, 참여 유도, 속도·컷 길이, 감정 흐름, 제목 유형, 성과 요인·약점을 구조화해 저장. 시청자 상위 댓글도 함께 저장.
3. **학습**: 특징마다 "그 특징을 쓴 영상이 평균보다 얼마나 잘 됐는지(lift)"를 계산. 표본이 적으면 0 쪽으로 보정해서 우연을 규칙으로 착각하지 않게 합니다.
4. **내 채널 피드백**: 올린 영상의 조회수와 **평균 시청 비율(유지율)**을 매일 측정해, 내 채널에서 실제로 통한 특징에 더 큰 가중치를 줍니다.
5. **적용**: 제작할 때마다 점수 높은 특징 + 일부 덜 검증된 특징(탐색)을 섞어 고르고, 직전 영상과 같은 도입 방식은 피합니다.
6. **주간 플레이북**: 분석 영상이 10편 이상이면 매주 AI가 글로 정리합니다.

## 6. 제작 방식 (화면 = "섞어서")

| 장면 | 방식 |
|---|---|
| 도입(훅)·챕터 시작 등 가장 중요한 장면 | **Gemini Omni Flash AI 영상** (기본 6개/편) |
| 나머지의 약 45% | **AI 이미지** (Gemini Nano Banana) + 천천히 확대·이동 효과 |
| 나머지 | **Pexels 무료 스톡 영상** |

실패하면 자동으로 다음 방식(AI영상 → AI이미지 → 스톡 → 제목 카드)으로 넘어갑니다.
음성: 채널에 지정한 목소리(내 목소리·Gemini·ElevenLabs). 지정이 없으면 Gemini TTS → ElevenLabs → OpenAI → 무료 Edge 순.
채널 목소리가 정해져 있으면 중간에 다른 목소리로 바뀌지 않습니다(실패하면 멈추고 '다시 시도'로 이어서 진행).
자막은 음성 타이밍에 맞춥니다. `pip install faster-whisper`를 해 두면 PC에서 무료로 음성을 다시 듣고 더 정확하게 맞춥니다.
설명란에는 챕터, AI 활용 고지, 스톡 출처가 자동으로 들어가고, 업로드할 때 "합성 콘텐츠 포함"으로 표시합니다.

## 7. 비용·한도 (설정 탭에서 조절)

- **하루·월·영상 1편 예산**을 넘으면 비싼 작업을 멈추고 더 싼 방식으로 대체합니다. 비용은 `data/settings.json`의 단가로 계산한 **추정치**이므로 실제 요금은 각 서비스 콘솔에서 확인하세요.
- **Gemini 무료 등급**: 유튜브 영상 시청이 하루 8시간 분량까지입니다. 유료 등급이면 설정에서 "예"로 바꾸면 제한이 풀립니다.
- **YouTube 할당량**: 기본 하루 10,000 단위입니다. 검색 1회에 100 단위가 들어서 하루 검색 수에 상한을 두었습니다.

## 8. 꼭 알아두실 것

- **수익화 정책**: 유튜브는 템플릿처럼 찍어낸 대량 AI 영상의 수익화를 채널 단위로 막습니다. 그래서 이 프로그램은 다음과 같이 동작합니다.
  - 영상마다 구성과 도입을 바꿉니다.
  - 이전 영상과 제목·도입이 비슷하면 다시 씁니다.
  - 기본값이 비공개 업로드라서 공개 전에 사람이 검토합니다.
  - 하루에 많이 올리기보다 검토 후 꾸준히 올리는 쪽이 안전합니다.
- **사실 확인**: AI 대본에는 틀린 사실이 들어갈 수 있습니다. 공개 전에 대본(제작 목록 → 장면)을 확인하세요.
- **저작권**: 남의 영상은 분석만 하고 내려받거나 재사용하지 않습니다. 배경음악 폴더(`assets/music`)에는 사용 허가된 음악만 넣으세요.
- **모델 이름**: AI 서비스들이 모델을 자주 교체합니다. 오류가 나면 `data/settings.json`의 `providers` 모델 이름만 바꾸면 됩니다.
  - 예: Veo 3.1 프리뷰는 2026-10-22에 종료되어 Gemini Omni Flash를 기본값으로 썼습니다.
  - OpenAI TTS(`gpt-4o-mini-tts`)는 2027-01-06 종료 예정입니다.
